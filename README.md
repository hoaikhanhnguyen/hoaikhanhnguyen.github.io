# Capstone Project Journey Blog

A personal blog documenting my 8-week capstone project journey to obtain 4 professional certifications.

## About

This blog serves as a learning journal where I document my progress, challenges, insights, and achievements as I work through each certification course. I'll be posting at least weekly with updates on my learning journey.

## What You'll Find Here

- **Weekly Progress Updates**: What I've accomplished and what I'm working on
- **Learning Highlights**: Key concepts, skills, and insights gained
- **Challenges & Solutions**: Real obstacles and how I overcome them
- **Resources & Tips**: Helpful materials and study strategies
- **Personal Reflections**: Thoughts on the learning process and growth

## Running Locally

This site is built with Jekyll. To run it locally:

```bash
# Install dependencies
bundle install

# Serve the site locally
bundle exec jekyll serve

# Visit http://localhost:4000 in your browser
```

## Adding New Posts

Create a new file in `_posts/` directory with the format:
```
YYYY-MM-DD-title-of-post.md
```

Include the front matter:
```yaml
---
layout: post
title: "Your Post Title"
date: YYYY-MM-DD
categories: [Category1, Category2]
---

Your content here...
```
